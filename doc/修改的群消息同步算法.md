# 一、统一定义（必须先统一）
1. **消息ID**：全局唯一、严格递增（msgId / seq）
2. **本地存储**：SQLite/Realm，按 msgId 有序存储
3. **加载方向**
   - **拉新（正向）**：拉取比本地最新 msgId 更大的消息（重连、在线收消息）
   - **拉历史（反向）**：拉取比本地最早 msgId 更小的消息（上滑加载更早）
4. **分页大小**：固定 PAGE = 100
5. **服务端必须返回**
   - list: 消息列表
   - hasMore: 是否还有更多历史
   - minId / maxId: 本次返回区间
6. **客户端状态（只存在内存/会话，不塞消息体）**
   - `isLoadingHistory`: 是否正在拉历史（防重复请求）
   - `isLoadingNew`: 是否正在拉新
   - `localNewestId`: 本地最新消息ID
   - `localOldestId`: 本地最早消息ID
   - `reachHead`: 是否已拉到群最早消息（不再拉历史）

# 二、整体架构原则（IM 铁律）
1. **本地数据只增不删**，绝不因空隙丢弃本地消息
2. **网络数据只补不覆**，重复消息按ID去重
3. **是否到头由服务器说了算**，不靠条数判断
4. **加载必须加锁**，同一时间只允许一个拉取请求
5. **标记状态存在会话，不污染消息体**

---

# 三、正确流程：登录/重连（拉新）
## 目标：补全离线期间漏掉的新消息
1. 从本地读取该群消息
2. 若无本地消息
   - 直接**拉历史**（从最新往早拉）→ 进入「拉历史流程」
3. 若有本地消息
   - 记录 `localNewestId`
   - 调用接口：`GetNewerMsg(localNewestId, PAGE)`
4. 处理返回
   - 去重，插入本地库
   - 若返回数量 == PAGE 且服务器说 `hasMore=true`
     → 继续递归拉新，直到拉完
   - 更新 `localNewestId`、`reachHead` 不变

> 重连只做一件事：**补最新**，不碰历史。

---

# 四、正确流程：上滑加载更早消息（拉历史）
## 入口条件
- 未 `reachHead`
- 非 `isLoadingHistory`

## 步骤
1. 加锁：`isLoadingHistory = true`
2. 取 `localOldestId`
3. 调用接口：`GetHistoryMsg(localOldestId, PAGE)`
4. 处理返回
   - 去重，插入本地库头部
   - 更新 `localOldestId`
   - 若 `hasMore == false`
     → 标记 `reachHead = true`，不再拉历史
5. 解锁：`isLoadingHistory = false`

> 历史只向后（更小ID）拉，永远不丢本地数据。

---

# 五、正确流程：本地缓存加载（打开群立刻显示）
1. 优先从本地加载最近 N 条（如 200 条）
2. 展示到 UI
3. 后台异步触发：
   - 拉新（补最新）
   - 不主动拉历史（等用户上滑）

# 六、消息去重与插入规则（全局唯一）
对每条网络返回消息：
```
if (msgId 不存在本地)
    插入本地
else
    忽略（或更新内容，如撤回、修改）
```
**绝不覆盖、绝不删除已有本地消息**。

---

# 七、空隙/断档处理（你原算法最大坑）
出现不连续（空隙）：
- **不丢数据**
- **不重置本地**
- 直接继续按方向拉取，服务器会自动补全
- 若服务器真的缺失（清理/撤回），客户端展示为正常间隔即可

IM 客户端**不负责修复服务端数据缺失**，只保证自己不乱。

---

# 八、边界判断规则（彻底替代你原来的【】*标记）
- 已到最早消息：`reachHead = true`
  → 由服务端 `hasMore=false` 决定
- 正在拉历史：`isLoadingHistory`
- 最新已拉完：拉新返回 < PAGE 或 hasMore=false

所有 UI 提示（“已到最早消息”）都从以上状态取。

# 九、极简伪代码（可直接翻译）
```
// 登录/重连
function onLoginOrReconnect() {
    localMsgs = db.queryRecent(GROUP_ID, 200)
    show(localMsgs)

    if (localMsgs.isEmpty()) {
        loadHistory(0)       // 从最新开始拉
    } else {
        loadNew(localMsgs.lastId)
    }
}

// 拉新：补离线消息
function loadNew(lastId) {
    if (isLoadingNew) return
    isLoadingNew = true

    resp = api.getNewerMsg(GROUP_ID, lastId, PAGE)
    insertOrIgnore(resp.list)

    if (resp.list.length == PAGE && resp.hasMore) {
        loadNew(getNewestId())
    }
    isLoadingNew = false
}

// 拉历史：上滑加载
function loadHistory(oldestId) {
    if (reachHead || isLoadingHistory) return
    isLoadingHistory = true

    resp = api.getHistoryMsg(GROUP_ID, oldestId, PAGE)
    insertOrIgnore(resp.list)

    if (!resp.hasMore) reachHead = true
    isLoadingHistory = false
}

// 去重插入
function insertOrIgnore(msgs) {
    for m in msgs {
        if (!db.exist(m.id)) db.insert(m)
    }
    refreshUI()
}
```
